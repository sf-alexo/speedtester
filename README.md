# speedtester

Консольный скрипт на Node.js для замера скорости скачивания по URL.

Делает **10 последовательных** GET-запросов к указанному адресу, дожидается полного ответа на каждый, затем считает среднее время, общий объём данных и скорость.

## Требования

- [Node.js](https://nodejs.org/) **18+** (используется встроенный `fetch`)

## Запуск

Без аргументов — дефолтный URL Cloudflare (1 МБ):

```bash
node speedtest.js
```

Свой адрес:

```bash
node speedtest.js <url>
```

или через npm:

```bash
npm start
npm start -- <url>
```

В zsh URL с `?` лучше брать в кавычки.

## Единицы измерения

| Метрика | Единица | Пояснение |
|---|---|---|
| Объём данных | B / KB / MB / GB | десятичные приставки (1 KB = 1000 B) |
| Время запроса | ms / s | миллисекунды или секунды |
| Скорость | **Mbps** и **MB/s** | мегабиты в секунду и мегабайты в секунду |

Скорость считается как:

```
скорость = общий_объём_байт / суммарное_время_всех_запросов
```

то есть по фактическому времени передачи всех 10 ответов.
